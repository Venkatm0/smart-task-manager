# Smart Task Management System

## Project Overview

The Smart Task Management System is a Flask-based web application developed using Python and PostgreSQL. The project allows users to manage daily tasks efficiently with authentication, task CRUD operations, analytics, and a responsive frontend UI.

---

## Features

- User Registration
- User Login & Logout
- Add Task
- Update Task
- Delete Task
- Get All Tasks
- Task Analytics Dashboard
- Responsive UI using HTML & CSS
- PostgreSQL Database Integration
- Pandas & NumPy Analytics

---

## Technologies Used

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- HTML
- CSS
- Pandas
- NumPy
